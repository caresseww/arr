第一章

总论：新生儿心律失常的世界

先建立全局：这个年龄段会发生什么、和儿童成人有什么本质不同、所有心律失常共享的三种机制——后面所有章节都建立在这三块地基上。

1.1疾病谱与发病率

新生儿心律失常的构成与儿童成人完全不同：大多数是良性的，病理性心律失常里以室上性为主，室性心律失常罕见但致命。

这张谱系表给读者的第一课：遇到新生儿心律失常，先验概率最高的是"不用治的早搏"，最不能漏的是 cAVB、LQTS 和 VT。后续章节反复回到这个框架。

1.2新生儿 ≠ 缩小的儿童：八组差异与六条底层原因

这些差异直接决定判读阈值、用药剂量和复苏流程——是整本读本的底层逻辑，后面各章不再重复解释。

维度✅ 新生儿❌ 儿童 / 成人（不要照搬）
SVT 阈值心率 >220 才考虑病理性 SVT>180 即考虑 SVT

差异背后的六条底层原因

  1. 心肌依赖外源钙 → 维拉帕米禁忌。新生儿心肌肌浆网发育不全，收缩高度依赖经 L 型钙通道的细胞外钙内流——钙通道阻滞剂等于直接抽掉收缩力。儿童 >1 岁肌浆网成熟后才可用。
  2. 传导系统是"半成品" → 自愈率高。房室结双径路未建立（AVNRT <10%）、异位灶自律性偏高（早搏占 71.4%）、旁路多为暂时性通路（40% 一年内消失）。很多心律失常的本质是"还没长好"，会随成熟消失——这是保守治疗的底层依据。
  3. 肝肾未成熟 → 地高辛减量。清除慢、半衰期延长，负荷与维持都按新生儿标准，并监测血药浓度。
  4. 糖原动员依赖 β2 → β 阻滞剂盯血糖。糖原储备少，升血糖的糖原分解通路依赖 β2 受体——β 阻滞剂 + 禁食 / 感染 = 低血糖。
  5. 骤停多为呼吸源 → CPR 通气优先。新生儿心跳骤停多是窒息 / 呼吸问题的终点——所以 NRP 通气优先、3:1、90 次/分。
  6. 迷走张力占优势 → 冰水敷面是一线。副交感占优，潜水反射能迅速拖慢房室结——成人几乎无效的物理方法，在新生儿是一线手段。

1.3三大电生理机制：一切心律失常的地图

新生儿心律失常无论表现多复杂，电生理机制只有三种。机制决定用药——这是全本读本最重要的一张地图。

① 折返（Reentry）：激动在环形通路中循环往复。折返的三要素：环形传导通路 + 通路某段单向阻滞 + 缓慢传导（其余部分已恢复应激）——本质是"传导速度不均一 + 不应期差异"。代表：SVT（AVRT / AVNRT）、房扑、典型 VT。

② 自律性增高：非起搏细胞（心房 / 心室 / 交界区）4 相自动除极异常加速，超过窦房结成为主导节律。代表：房速 AT、交界速 JET、室性逸搏 / 加速。

③ 触发活动：动作电位后出现异常后除极（EAD / DAD），达到阈电位触发新激动，与钙超载、QT 延长相关。代表：TdP（尖端扭转型室速）、地高辛中毒心律失常。

为什么机制决定用药
折返性对腺苷 / 电复律敏感——延长不应期即打断折返环；自律性增高对腺苷不敏感——腺苷只作用于房室结、不影响异位灶，需用抑制 4 相自律性的药物（β 阻滞剂 / 胺碘酮 / 氟卡尼）；触发活动（TdP）首选镁盐（抑制后除极），禁用延长 QT 的药物。动作电位层面的解释见 2.1。
第二章

基础：读懂新生儿心电图

判断的前提是知道"正常"。本章给四样东西：电生理底座、正常值、每个波的意义、床旁测量方法。

2.1电生理基础：动作电位与不应期

0 相（除极）：心房、心室、希浦系肌细胞靠快钠通道开放除极——钠通道阻滞剂（I 类）作用于这里减慢传导；窦房结和房室结是钙依赖的慢反应细胞，0 相上升慢、传导慢——所以房室结是心房的"闸门"，腺苷（延长不应期）在这里起作用。

2–3 相（复极）：钾外流逐渐完成复极，对应 ECG 的 QT 间期。复极延长 → 3 相出现早期后除极（EAD）→ 触发活动 → TdP。钾通道阻滞剂（III 类，胺碘酮 / 索他洛尔）延长复极——所以它们能终止折返，但也延长 QT，LQTS 禁用。

4 相（舒张期自动除极）：自律性的来源。窦房结 4 相除极最快所以是主导起搏点；心房、交界区、心室都有潜在起搏能力，正常时被"超速抑制"——它们的 4 相除极异常加速，就是自律性增高型心律失常（AT / JET / 室性逸搏）。

不应期：动作电位期间心肌对新刺激无反应。房室结不应期最长——它是保护心室的闸门，也是折返最容易被"卡住"的位置。

2.2正常值与发育特点

足月儿清醒心率 110–160；PR 0.08–0.12s（比成人短——房室结传导通路尚未拉长）；QRS <0.08s；QTc <470ms；II 导 P 正向、aVR 负向。发育特点：新生儿窦房结固有频率高于成人（所以 220 才是 SVT 的门槛，见 1.2）；P 波小、T 波可 V1 倒置。

2.4床旁测量方法

走纸速度：常规 25mm/s——小格 0.04s、大格 0.2s。新生儿病房常用 50mm/s（P 波小、心率快，拉开一倍更好认）——此时所有间期读数是常规的 2 倍，先看标注再读数，别把间期量成两倍。

心率估算（规则心律）：25mm/s 下心率 ≈ 300 ÷ RR 大格数；50mm/s 下 ≈ 600 ÷ RR 大格数。

找 P 波：II 导和 V1 最清楚。P 找不到时先想"埋进 QRS / T 波里"（SVT），再想"根本不是窦性 P"（交界性）。

QT / QTc：从 QRS 起点量到 T 波终点，选 T 波最清楚的导联；QTc = QT/√RR。极快心率时 Bazett 有高估倾向——判断 LQTS 要在窦性心律、无电解质紊乱时复查确认，不能只凭发作图。

第三章

方法：拿到一张心电图怎么想

固定顺序的分析框架——30 秒出方向，然后用鉴别表收口。每一型的完整知识在第五章，本章只给方法。

3.1五步分析法：率 → 律 → 宽 → P → QTc

  1. 看心率。>220 警惕 SVT；<100（清醒）警惕窦缓 / cAVB。依据：新生儿窦房结固有频率高于成人，220 是病理性的门槛（成人儿童 180 即警惕，见 1.2）。
  2. 看节律（RR 规则吗）。绝对规则 + 突发突止 → SVT（折返环固定，开/关像开关）；绝对不齐 → 房颤 / 多源早搏（多个起源点各跳各的）；规则而慢 → cAVB（逸搏节律规则而缓慢）。
  3. 看 QRS 宽度。窄（<0.08s）→ 激动走正常希浦系统，室上性来源；宽 → 心肌内缓慢传导，VT 或室上性伴差传（新生儿差传极罕见，决策逻辑见 5.7）。
  4. 看 P 波与 QRS 的关系。这是机制的直接呈现：P 埋藏 → SVT；锯齿波 → 房扑；P 形态异常 → 房速；P 与 QRS 各跳各的 → cAVB 或 JET（看房率谁快谁慢：房率>室率 = cAVB，房率<室率 = JET）。
  5. 看 QTc。>470 警惕 LQTS；>500 高危；伴 2:1 房室阻滞 = 极高危（机制见 5.6）。
口诀
率律宽 P 轴——窄快规则=SVT；窄快锯齿=房扑；窄快异常P=房速；窄快房室分离=JET；宽快=VT；慢而无关=cAVB；QT长=LQTS。

3.3两个经典的"伪装"

未下传 PAC 伪装窦缓
房性早搏来得太早，房室结还在不应期，P′ 后没有 QRS——形成长间歇，监护仪报"心动过缓"。鉴别：长间歇前的 T 波里藏着形态不同的 P′ 波。看清了无需任何处理，最怕当窦缓去装起搏器。机制详见 5.8。
窦缓 vs cAVB
都有慢而规则的 RR。看 P-QRS 关系：窦缓每个 P 跟一个 QRS（1:1，PR 固定）；cAVB 的 P 与 QRS 各跳各的，且房率 > 室率。详见 5.5。

良性早搏的 6 条良性标准与 7 条需评估指征，在 5.8 一并给出——它是最常遇到的"判断题"。

第四章

急症处理：最先要会的一章

处理病人的完整流程，自成一个闭环：先保住血流动力学，再谈诊断。每一型"为什么"在各论与治疗学中展开。

4.1监护仪报警后的第一分钟：做五件事

  1. 看孩子，不只看数字。肤色、呼吸、反应、肢端温度、毛细血管再充盈——同样的心电图数字，灌注好坏是两条路。
  2. 12 导联心电图。治疗可以开始于单导联判读，但最终诊断必须落在 12 导联上（QRS 宽窄、P 波位置、QTc、预激波都只有 12 导联看得全）。
  3. 持续心电监护 + 建立静脉通路。通路尽量选大静脉（如肘正中）——腺苷要在几秒内以原浓度到达房室结，细静脉必然失败。
  4. 快速评估稳定性（4.2）——这是后续一切处理的分水岭。
  5. 抽血：血气 + 电解质（K/Mg/Ca）+ 血糖。可逆因素一半在这里（4.7）。

4.2稳定性评估：处理路线的分水岭

不稳定的表现（任何一条即算）：低血压 / CRT>3 秒、四肢凉或花纹、意识改变、呼吸窘迫、乳酸升高或代谢性酸中毒、心衰征象（肝大、水肿）。

为什么它是分水岭：不稳定说明心脏"此刻的输出不足以维持灌注"，等药物起效的时间都等不起——所以直接电复律；稳定则有时间让药物发挥作用，从最简单、副作用最小的一步开始。拿不准时，按不稳定处理。

4.3不稳定 → 立即同步电复律

行动
首剂 0.5–1 J/kg，无效 2 J/kg。不要因等待镇静而延迟。复律后予抗心律失常药维持。同步 / 非同步的选择原理与操作细节见 6.3。

4.4稳定 → 按 QRS 宽窄和心率分路用药

三条路
窄 QRS 快而规则（多为 SVT）→ 4.5 三步法；
宽 QRS → 一律先按 VT：胺碘酮 5 mg/kg 或利多卡因 1 mg/kg（决策逻辑见 5.7）；
心率慢 → cAVB 路径：室率 <55 或 55–70 伴低灌注 → 起搏（5.5）；
药物无效 → 电复律。

4.5稳定 SVT 的三步法：冰 → 苷 → 电

  1. 冰：冰水毛巾敷前额 + 鼻梁 15–30 秒。原理：新生儿迷走张力高（1.2），冷刺激触发潜水反射，迷走冲动减慢房室结传导——SVT 的环路必经房室结，拖慢它环路就断。
  2. 腺苷：0.2 mg/kg 大静脉弹丸式 3 秒内推注 + 5 mL 生理盐水冲管；无效递增 0.1 mg/kg，最大 0.3 mg/kg。原理：腺苷延长房室结不应期，打断折返环的前传支（机制见 5.1）。
  3. 电：药物无效 → 同步电复律 0.5–1 → 2 J/kg。
腺苷"无效"的真相
90% 是操作问题：推注速度不够 / 血管太细 / 没冲管——腺苷半衰期只有约 10 秒，必须让它以原浓度冲到房室结。不推荐经脐血管给药。另外记住：腺苷只终止折返性心律失常（SVT）；对房速、JET、房扑本来就不会终止（机制见 1.3），不要据此反复加量。

4.6心跳骤停：按 NRP，不是 PALS

通气优先，按压 : 通气 = 3 : 1，按压速率 90 次/分。为什么不同：新生儿骤停多为呼吸问题（窒息）的终点，肺里没有气，按压再好也无效（底层原因见 1.2）；儿童 / 成人才是心源为主、按压优先（PALS 15:2、100–120 次/分）。

除颤（VF / 无脉 VT）：4 J/kg。肾上腺素：0.01–0.03 mg/kg IV/IO，每 3–5 分钟。抗心律失常：胺碘酮 5 mg/kg 或利多卡因 1 mg/kg。

4.7可逆因素：人人都要查一遍

低氧 · 酸中毒 · 低钾 / 低镁 / 低钙 · 低体温 · 低血糖 · 药物毒性（地高辛 / 茶碱）。

为什么纠因等于治疗
电解质紊乱和低氧直接改变心肌电生理：低钾低镁既诱发心律失常、又是地高辛中毒的土壤；酸中毒降低自律性阈值与除颤成功率。目标 K⁺ 维持 4.0–5.5。纠正之后很多"顽固"心律失常自己就终止了——所有心律失常的处理都包含这一步。

4.8需要立即呼叫上级 / 心内科的红线

  • 血流动力学不稳定，需要电复律 / 除颤
  • 室率 <55（cAVB），或 55–70 伴低灌注
  • QTc >500 ms，或 QTc 延长伴 2:1 房室阻滞
  • 宽 QRS 心动过速（先按 VT 处理，同时呼叫）
  • 腺苷两次规范推注无效，或诊断不明且病情在恶化
第五章

各论：八型心律失常

每型一个完整章节：定义与流行病学 → 机制 → 心电图（含读图实例）→ 分型亚型 → 处理 → 长期转归 → 禁忌陷阱。顺序按床旁出现频率与危险度。

5.1SVT 室上性心动过速最常见病理性心律失常 · 发病率 1:250–1:1000

口诀
窄快规则突发止，90% 是旁路（AVRT），冰水腺苷是首选，40% 一岁自己好。

机制折返 · AVRT 为主

AVRT（房室折返性心动过速，约 90%）：激动经正常房室结下传心室，再经旁路（accessory pathway）逆传心房，形成大折返环。旁路传导速度快、不应期短。40% 旁路在 1 岁内自行消失（传导系统成熟）——这是新生儿 SVT 预后好的关键，也是"药物维持到 1 岁再评估停药"的依据。

AVNRT（房室结折返性心动过速，<10%）：房室结内存在双径路（快径 + 慢径），激动在两条径路间折返。新生儿少见，因房室结尚未发育出成熟的双径路结构（1.2 底层原因 2）。

为什么冰水和腺苷都有效：折返环的前传支都要走房室结。冰水敷面激活潜水反射、迷走张力骤增，减慢房室结传导；腺苷直接延长房室结不应期——都是打断前传支，使环路中断。电复律同理：一次电击让全部心肌同时除极、同步复极，折返环消失。

心电图特征

SVT 示意 · 窄快规则 · P 波埋藏
读图实例（真实病例）：15 天男婴 · 心率约 310 次/分 · 走纸 50mm/s · 窄 QRS 规则 · 无可见 P 波

心率 220–300 bpm，RR 绝对规则，突发突止；P 波埋藏于 QRS 中或 T 波终末，或见逆行 P 波（II/III/aVF 负向；RP 短 <70ms 提示 AVNRT，>70ms 提示 AVRT）；QRS 通常窄（<0.08s），伴差传时可宽；ST-T 改变常见（继发性）；发作间期与窦律对比可见预激波（δ 波）提示 WPW。

急性处理

稳定：冰 → 苷 → 电（流程与原理见 4.5）；二线：普鲁卡因胺 / 胺碘酮 / 艾司洛尔。不稳定：立即同步电复律 0.5–1 → 2 J/kg，复律后予抗心律失常药维持。

长期管理与合并症

地高辛（非预激）10 μg/kg/d 或普萘洛尔 2–4 mg/kg/d；全量至 6 月龄，维持至 1 岁评估停药。合并症：60–70% 无 CHD；20–30% 合并 CHD（Ebstein / L-TGA——所以 SVT 患儿要查心脏超声）；6–10% 合并 WPW。

禁忌 / 注意
WPW 预激者禁用地高辛（增加室颤风险）；β 阻滞剂需监测低血糖；不推荐经脐血管给腺苷。

5.2房扑 / 房颤新生儿相对多见 · 占快速心律失常 18% · 房率 300–500

口诀
锯齿 F 波无等电线，房率三百到五百，Ic 类药必配阻滞剂，否则 1:1 传导要完蛋。

机制房扑 = 大折返 · 房颤 = 多子波

典型房扑：激动在右心房内沿三尖瓣环做大折返（三尖瓣峡部依赖），顺时针或逆时针方向运行。折返环固定，所以 F 波形态一致、节律规则——这也解释了为什么电复律一次成功率高（折返环稳定，一击即断）。

房颤：心房内存在多个混乱的微折返子波，无统一激动顺序，所以 P 波消失、RR 绝对不齐。新生儿极罕见，多合并 Ebstein 畸形或 WPW——见到房颤先想这两种病。

为什么 Ic 类药危险：氟卡尼 / 普罗帕酮减慢房率（300→200），但不抑制房室结传导——原来 2:1 传导（室率 150）的房室结"来得及"每跳都下传，变成 1:1 传导（室率 200+），室率反而更快，可致休克。所以 Ic 类必须联合地高辛或 β 阻滞剂"锁住"房室结。

心电图特征

房扑示意 · 锯齿 F 波 · 2:1 传导
读图实例（真实病例）：新生儿房扑 · 腺苷后暴露典型锯齿 F 波 · 2:1 房室传导

心房率 300–500 bpm，锯齿状 F 波，II/III/aVF 多负向（典型房扑）或正向（非典型），无等电线（关键鉴别点）；房室传导 2:1（最常见，室率 150–250）或变异传导；QRS 通常窄；腺苷可增加房室阻滞暴露 F 波（有助诊断，但不终止房扑）。

急性处理

不稳定：电复律 0.5–1 J/kg（成功率高）。稳定：地高辛（减慢室率）+ 普鲁卡因胺 / 氟卡尼（转复）；难治用胺碘酮。另有 TEAP（经食管心房超速起搏）——无创、可重复、不需镇静，新生儿耐受性好。

长期管理

转复后地高辛 ± β 阻滞剂维持 3–6 个月；新生儿房扑复发率低，多数婴儿期后不再发作。

最大陷阱 + 房颤
Ic 类（氟卡尼 / 普罗帕酮）用于房扑时必须联合 AV 阻滞剂（地高辛或 β 阻滞剂）！否则房率减慢后 2:1→1:1 传导，室率骤升可致死。
房颤（极罕见）：P 波消失、RR 绝对不齐；多合并 Ebstein / WPW；WPW 合并房颤禁用腺苷和地高辛，首选普鲁卡因胺或电复律。

5.3AT 房性心动过速占快速心律失常 5–10% · 含局灶性 / 多源性房速

口诀
异常 P 波规则快，房率两百到三百，地高辛 β 阻是首选，腺苷不终止只暴露，多数一岁自己好。

机制自律性增高为主

局灶性房速（EAT，最常见）：心房内某一异位灶（常见于界嵴、肺静脉口、冠状窦口）自律性异常增高，超过窦房结成为主导节律。新生儿心房肌非起搏细胞自律性本身较高（未成熟，1.2），在低氧、酸中毒、感染、围生期窒息时更易增高——纠因本身就是治疗。

多源性房速（MAT）：≥3 个不同心房异位灶交替发放，P 波形态 ≥3 种，RR 绝对不齐。多见于肺部疾病（RDS、肺炎）、低氧、茶碱 / 咖啡因毒性——治肺比治心重要。

为什么腺苷不终止 AT：腺苷只作用于房室结（延长不应期），不影响心房异位灶的自律性——灶还在跳。但腺苷可增加房室阻滞，使原本 1:1 传导变成 2:1，把隐藏在 QRS 中的 P 波形态暴露出来——这是诊断价值，不是治疗作用。

心电图特征

房速示意 · 异常 P 波 · 可伴房室阻滞

P 波形态异常（非窦性 P 波）：II/III/aVF 可负向、低平或切迹，aVR 可正向（提示低位房速）；心房率 180–300 bpm；可伴不同程度房室传导阻滞（2:1 或变异传导）；QRS 通常窄；RR 可规则（固定传导）或不规则（变异传导）——室率可以不高，要数 PP 间期。

分型

局灶性房速（EAT）：单一异位灶，P 波形态一致，RR 较规则。多源性房速（MAT）：≥3 种 P 波形态，RR 绝对不齐，多见于肺部疾病 / 低氧。无休止性房速：持续 >12h，可致心动过速性心肌病——需积极控制心率，不能"等着它自己好"。

急性处理

稳定：地高辛（负荷 30–40 μg/kg 分 3 次 → 维持 10 μg/kg/d）或普萘洛尔 2–4 mg/kg/d；难治 → 胺碘酮 5 mg/kg IV 或普罗帕酮 / 氟卡尼；伊伐布雷定 0.1–0.2 mg/kg/d 用于难治性（最新证据）。不稳定：立即同步电复律 0.5–1 → 2 J/kg，复律后予抗心律失常药维持。

长期管理与转归

地高辛 ± β 阻滞剂维持 3–6 个月；多数在婴儿期自行缓解（异位灶成熟消退）；难治性 / 无休止性 → 小儿电生理评估，年龄大后可射频消融。

禁忌 / 注意
腺苷通常不终止 AT（但可增加房室阻滞暴露 P 波，有助诊断）；WPW 合并 AT 时禁用地高辛；持续 AT 可致心动过速性心肌病，需积极控制心率；纠正低氧 / 电解质 / 感染。

5.4JET 交界性异位心动过速先天性罕见 · 术后常见 · 先心术后发生率 5–22%

口诀
窄 QRS 房室分离，心率一百六到两百一，腺苷不终止只分离，胺碘酮是第一线，术后镇静加降温。

机制交界区自律性增高

先天性 JET：房室结 / 希氏束区域的自律性细胞异常增高，超过窦房结成为主导节律。可与母体抗 Ro/La 抗体相关（炎症损伤传导系统）、心肌炎、心肌病。

术后 JET：心脏手术（尤其 TOF、VSD 修补）对房室结区域的创伤、水肿、缺血、炎症，导致交界区自律性一过性增高。术后 24–72h 高发，多为一过性——"伤口肿了在乱放电，肿消了就好"。

为什么房室分离：交界区激动下传心室（产生 QRS），但逆传心房的能力弱或不稳定——心房仍由窦房结控制（产生 P 波），P 与 QRS 各跳各的，房率慢于室率。

为什么腺苷不终止：JET 的异位灶就在房室结内，腺苷虽作用于房室结，但对已经增高的自律性灶抑制有限，只能加重房室分离（使逆传更困难），不能终止心动过速——不要误以为无效就加量。

心电图特征

JET 示意 · 房室分离 · 房率慢于室率

心率 160–210 bpm；窄 QRS（除非伴差传）；房室分离——P 波与 QRS 无关，房率慢于室率；逆行 P 波（II/III/aVF 负向，RP 短）或无 P 波；QRS 形态正常；腺苷可致 VA 分离加重但不终止心律失常；可有窦性夺获 / 融合波。

分型

先天性 JET：出生时即存在，罕见，可与母体抗 Ro/La 相关、心肌炎、心肌病；常需长期药物治疗。术后 JET：先心术后 24–72h 出现（尤其 TOF、VSD 修补后），手术创伤 + 炎症 + 缺血所致；多为一过性。

急性处理

先天性：胺碘酮 5 mg/kg IV（一线，60% 有效）± 普萘洛尔 / 氟卡尼联合；难治 → 伊伐布雷定 0.1–0.2 mg/kg/d（最新证据，可单药治疗）；不稳定 → 电复律。

术后——核心是纠正诱因，不是堆药：镇静镇痛（咪达唑仑 + 吗啡）撤掉交感刺激；降温 34–35℃（交界区自律性受交感张力和温度驱动，降温直接降自律性）；纠正电解质（低钾 / 低镁）；优化容量；减少正性肌力药。药物：胺碘酮（一线）或普鲁卡因胺；必要时心房超速起搏（AAT）——用更快的房率夺获心房，恢复房室同步、抬高心输出量。

长期管理与转归

先天性 JET 常需联合药物治疗（胺碘酮 + β 阻滞剂）；部分需射频消融（年龄大后，成功率 80–85%）。术后 JET 多为一过性，数天至数周自行缓解，不需长期用药。

禁忌 / 注意
腺苷不终止 JET（只致 VA 分离），不要误以为无效就加量；术后 JET 核心是镇静 + 降温 + 纠正诱因，不是单纯加抗心律失常药；先天性 JET 可致心衰和死亡，需积极治疗；房室不同步时心输出量下降，可考虑心房起搏。

5.5cAVB 完全性房室传导阻滞60% 与母体抗 Ro/La 相关 · 发病率 1:15000–1:20000

口诀
P 和 QRS 各跳各的，室率五十五是红线，低于五十五就起搏，妈妈一定要查抗 Ro/La。

机制传导中断 + 逸搏接管

自身免疫性（60%）：母体抗 Ro/SSA、抗 La/SSB 抗体经胎盘进入胎儿，攻击房室结区域的传导细胞，导致炎症、纤维化、钙化，最终完全中断房室传导。母亲可能完全无症状（干燥综合征 / 狼疮），但抗体阳性——所以查的是母亲血，不是患儿。

先天性心脏病相关（40%）：L-TGA（矫正性大动脉转位）、房室间隔缺损、左室流入道畸形等，传导系统解剖异常或缺如。

逸搏心律：房室结以下的次级起搏点接管心室节律。交界逸搏（QRS 窄，率 60–80）位点高、较稳定；室性逸搏（QRS 宽，率 <60）位点低、不稳定，易发生停搏和猝死。

听诊线索：P 与 QRS 无固定关系 → 房室收缩组合每次都不同 → 第一心音强弱不等；偶尔心房心室同时收缩（三尖瓣开放时心房收缩、血倒流）→ 响亮的"大炮音"——听诊就能提示 cAVB。

心电图特征

cAVB 示意 · P 与 QRS 完全无关 · 房率快于室率

P 波与 QRS 完全无关（房室分离），房率 > 室率，PP 规则、RR 规则但 P 与 QRS 无固定关系；室率 60–80 bpm（交界逸搏，QRS 窄）或 <60 bpm（室性逸搏，QRS 宽，更危险）；第一心音强弱不等，可闻大炮音；QTc 可延长。与窦性心动过缓鉴别：窦缓有 1:1 P-QRS 关系，cAVB 没有（3.3）。

紧急起搏指征（红线）

为什么 55 是红线：新生儿心输出量 = 心率 × 每搏量，且每搏量的代偿余地小——心率就是心输出量。① 室率 <55 bpm 立即起搏；② 室率 55–70 伴心衰 / 低灌注 / 乳酸高——储备已耗尽，不要等数字掉到 55；③ 室性逸搏（宽 QRS、不稳定）本身即指征；④ 胎儿水肿 / 心功能不全。

临时桥接与永久起搏的方式见 6.4——药物只是桥接，起搏才是唯一根治。

病因排查与高危

必须查母亲抗 Ro/SSA、抗 La/SSB 抗体（60% 相关）；其余与 CHD 相关（L-TGA、房室间隔缺损）；查心肌炎、心肌病。

高危
合并胎儿水肿者死亡率 20–30%；合并 EFE（心内膜弹力纤维增生症）预后差；出生后 24–48h 室率可能快速下降，需 NICU 密切监护；室性逸搏（宽 QRS）比交界逸搏（窄 QRS）危险得多。

5.6LQTS 长 QT 综合征占非良性心律失常 10.7% · 发病率 1:2000

口诀
QTc 超过四百七，立即上普萘洛尔，不等基因结果；尖端扭转用镁盐，补钾提速是关键，延长 QT 药全禁。

急性 TdP 处理（为什么这么配）

硫酸镁 25–50 mg/kg IV（一线，特异性抑制 EAD——对"复极延长"的土壤起效）＋ 补钾至 4.5–5.0（钾通道电流依赖胞外钾）＋ 提高心率至 90–110（异丙肾上腺素 / 临时起搏——心率快则每搏复极时间短，QT 物理性缩短，EAD 没机会成形）。室颤时 4 J/kg 除颤。

长期治疗

普萘洛尔 2–3 mg/kg/d 分 3–4 次（可至 4 mg/kg）——立即启动，不等基因结果（降低交感触发 + 缩短动作电位）；LQT3 加用美西律 2–5 mg/kg/d（阻断延迟钠内流）。

避免诱因与遗传筛查

LQT1 避免剧烈运动 / 游泳；LQT2 避免突然声响（闹钟 / 门铃远离婴儿床）；LQT3 睡眠时发作风险高；避免所有延长 QT 的药物（crediblemeds.org）。常染色体显性遗传；一级亲属均需 ECG + 基因检测。

高危 / 禁忌
2:1 阻滞 = 新生儿 LQTS 高危征象；占 SIDS 5–10%；禁用胺碘酮、索他洛尔（延长 QT）；家属需 CPR 培训；通常需终身 β 阻滞剂。

5.7VT 室性心动过速 / VF 室颤罕见但致命 · 多为继发性

口诀
宽 QRS 房室分离，室速胺碘酮利多卡，室颤除颤四焦每公斤，先找病因是关键。

机制与病因三种机制对应三组诱因

折返性 VT——心肌瘢痕 / 纤维化区域形成缓慢传导区，激动在瘢痕周围折返。多见于心肌炎、心肌病、先心术后。自律性 VT——心室异位灶自律性增高，多见于心肌缺血、低氧、酸中毒。触发活动性 VT（TdP）——EAD / DAD 触发，见于 LQTS、地高辛中毒、电解质紊乱。VF 机制：多个微折返子波在心室内混乱运行，无统一激动顺序，心室失去有效收缩——需立即除颤"重启"。

为什么宽 QRS 一律先按 VT：① 新生儿室上速伴差传极罕见，鉴别的先验概率极低；② 误判代价不对称——把 VT 当 SVT 治（尤其误用维拉帕米 / 地尔硫卓）可致死，反过来按 VT 治（胺碘酮）只是偏保守。规则简单粗暴：宽 QRS = VT，直到证明不是。

心电图特征

VT 示意 · 宽 QRS · 房室分离
读图实例（真实病例）：室速 · 胸导联 V1–V6 全部负向（负向一致性）· 宽 QRS 0.2s · 心率 160

VT：QRS 宽大畸形（>0.08s），心率 150–250 bpm，节律可规则或略不规则；房室分离（P 与 QRS 无关，房率慢于室率）；可有窦性夺获波（窄 QRS 插入）和融合波（形态介于两者之间）——两者是房室分离的实锤，看到即可确诊 VT；胸导联 V1–V6 全部负向（负向一致性）强烈支持 VT。VF：无规律、杂乱的波动，无明确 QRS 波，振幅可大（粗颤）或小（细颤）。

病因（必须查）

心肌炎（最常见）、心肌病、先心术后、LQTS / TdP、电解质紊乱（低钾 / 低镁 / 低钙）、低氧 / 酸中毒、地高辛中毒、心肌缺血。VT 是心电图表现，不是诊断终点——胺碘酮稳住之后，病因决定长期结局。

急性处理

稳定：胺碘酮 5 mg/kg IV 缓推（首选，广谱——三种机制都覆盖）或利多卡因 1 mg/kg IV → 20–50 μg/kg/min（优先作用于缺血 / 异常心肌）；TdP：硫酸镁 25–50 mg/kg；同时纠正电解质和低氧。

不稳定 / VF：VT → 立即同步电复律 0.5–1 → 2 J/kg；VF → 立即非同步除颤 4 J/kg → CPR（NRP 3:1，4.6）→ 肾上腺素 0.01–0.03 mg/kg → 胺碘酮 5 mg/kg → 再除颤；细颤先 CPR 变粗颤再除颤。

长期管理

治疗基础病因（心肌炎 / 心肌病）；胺碘酮或 β 阻滞剂维持；难治性 → 植入 ICD（体重足够后）；射频消融（特定折返性 VT）。

禁忌 / 注意
宽 QRS 心动过速一律先按 VT 处理，不要试图鉴别室上速伴差传（新生儿罕见）；维拉帕米绝对禁用（可致休克 / 死亡）；VF 时 CPR 按 NRP（3:1）非 PALS；细颤先 CPR 变粗颤再除颤。

5.8良性早搏（PAC / PVC）占全部心律失常 71.4% · 绝大多数不用治

口诀
房早室早最常见，代偿间歇分完全，单源偶发不用治，多源连发要警惕。

机制异位灶提前发放

房性早搏（PAC）——为什么代偿不完全：心房内异位灶提前发放一次激动，下传心室产生 QRS；异位激动侵入窦房结、重置了它的"钟"，下一个窦性激动从重置点重新计时——早搏前后两个窦性 RR <2 倍基础 RR（代偿不完全）。

室性早搏（PVC）——为什么代偿完全：心室内异位灶提前发放，产生宽大畸形 QRS，通常不逆传心房（或逆传不完全），窦房结节律丝毫没被打扰——早搏前后两个窦性 RR = 2 倍基础 RR（代偿完全）。

新生儿为什么最多见（71.4%）：心脏传导系统未成熟，心房 / 心室肌细胞自律性较高，在迷走神经张力变化、喂养、睡眠周期中容易出现异位搏动。多数随年龄增长自行消失——这是"观察 + 随访"的底气，也是"不用药"的原因：抗心律失常药的促心律失常风险 > 早搏本身的风险。

心电图特征

PAC 与 PVC 示意
读图实例（真实病例）：室早二联律与三联律 · 宽 QRS 提前出现 · 完全代偿间歇

PAC：提前出现的 P 波（形态与窦性 P 不同，可低平 / 倒置 / 隐藏于前一 T 波中）；P′R 间期可正常或延长；QRS 通常窄（伴差传时可宽）；代偿间歇不完全；可未下传（P′ 后无 QRS，易误诊为窦缓，见 3.3）。PVC：提前出现的宽大畸形 QRS（>0.08s），其前无相关 P 波；T 波方向与 QRS 主波相反；代偿间歇完全；单源形态一致，多源形态各异；可呈二联律 / 三联律。

良性判断标准（全部满足才算良性）

① 单源（形态一致）；② 偶发（<10 次/分或 <10% 心搏）；③ 无连发 / 成对 / 短阵 VT；④ 无器质性心脏病；⑤ 活动后减少（良性特征）；⑥ 无症状（无低灌注 / 心衰）。

需进一步评估（任何一条）

① 多源 PVC；② 频发（>10%）；③ 连发 / 成对 / 短阵室速；④ 活动后增多；⑤ 合并器质性心脏病 / 心肌炎 / 心肌病；⑥ 有症状（低灌注 / 心衰）；⑦ PVC 形态异常（如 R-on-T）。

处理

良性早搏：无需抗心律失常药，安抚家长，定期随访 Holter。有症状 / 频发 / 合并心脏病：治疗基础病，必要时 β 阻滞剂（普萘洛尔）。未下传 PAC 致长间歇：一般无需处理，避免误诊为窦缓而起搏。新生儿 PVC 多数在 1 岁内消失。

注意
不要给良性早搏用抗心律失常药（弊大于利）；未下传 PAC 易误诊为窦性心动过缓，仔细看 T 波中是否隐藏 P′ 波；Holter 评估比单次 ECG 更有价值。

6.3电复律与除颤

同步 vs 非同步：同步放电靠 R 波触发，避开 T 波终末部的易颤期——用于一切 QRS 可识别的心动过速（SVT / VT / 房扑不稳定时）；VF / 无脉 VT 的 QRS 无法识别，必须用非同步除颤。

能量：同步 0.5–1 J/kg 起、无效 2 J/kg（递增逻辑：首次低能量足以终止折返，失败即翻倍）；除颤 4 J/kg。

电极板：前后位或前侧位，导电耦合充分、两板不要相互接触。

镇静：已稳定的患儿可快速镇静后再复律；不稳定者不因等待镇静延迟。

细颤：VF 波幅过低（细颤）时先 CPR 改善灌注变粗颤，再除颤。

6.4起搏治疗

临时桥接药物（等待起搏时）：异丙肾上腺素 0.05–1 μg/kg/min IV（β 激动剂，提高交界区自律性）；特布他林口服 / 皮下；阿托品 0.02 mg/kg（对希氏束以下阻滞无效）。起搏指征本身在 5.5（室率 55 红线）。

永久起搏：先天性 cAVB 多数最终需要；新生儿 / 小婴儿首选心外膜起搏器（胸骨下入路，囊袋置腹部）；体重 >15kg 后可经静脉。术后 JET 房室不同步时，可临时心房超速起搏（AAT）恢复房室同步（5.4）。

6.5绝对禁忌与高危陷阱

1 · 维拉帕米（含地尔硫卓，任何途径）
可致顽固性低血压、休克、心脏停搏——新生儿心肌依赖钙内流维持收缩力（底层原因 1，1.2）。宽 QRS 心动过速同样禁用。儿童 >1 岁肌浆网成熟后才可用。
2 · WPW 预激 + 房颤 / 房扑
禁用腺苷、地高辛、维拉帕米——阻断房室结后，房颤 / 房扑的激动全部经旁路下传（旁路不该承担 1:1 传导），可致室颤。首选普鲁卡因胺（延长旁路不应期）或电复律。
3 · LQTS
禁用胺碘酮、索他洛尔及所有延长 QT 的药物（抗生素也要查 crediblemeds.org）——在复极已经延长的土壤上再加延长，等于直接播种 TdP。

高危组合 / 陷阱清单

  • Ic 类药用于房扑必须联合 AV 阻滞剂，否则 1:1 传导室率骤升（机制见 5.2）
  • 腺苷必须大静脉快推 + 冲管，外周小静脉效果差（4.5）
  • 未下传 PAC 易误诊为窦性心动过缓，看 T 波中隐藏 P′ 波（3.3）
  • cAVB 室率 55–70 伴低灌注即需起搏，不要等 <55（5.5）
  • 术后 JET 核心是镇静 + 降温 + 纠正诱因，不是单纯加抗心律失常药（5.4）

6.6用药前必查

  • 12 导联 ECG：QRS 宽窄、P 波关系、QTc、预激波
  • 电解质：K⁺（4.0–5.5）、Mg²⁺、Ca²⁺——低钾低镁诱发心律失常和地高辛中毒
  • 血糖：β 阻滞剂可致低血糖，尤其禁食新生儿（底层原因 4，1.2）
  • 肝功能 / 甲状腺功能：胺碘酮长期使用前基线
  • 地高辛血药浓度：维持 1–2 ng/ml，中毒 >2.5
第七章

长期管理与随访

急性期过后，管理的主线是"何时减药、何时停药、什么时候能让家长放心"——核心依据是 1.2 讲过的自愈规律。

7.1随访节奏

出院前完成 12 导 ECG + 24h Holter + 心脏超声；明确心律失常类型和病因；制定药物方案和剂量；家长 CPR 培训；LQTS / cAVB 家属遗传咨询
2 周首次随访：评估药物耐受性（心率、血压、血糖）；地高辛血药浓度（如使用）；ECG 复查；调整剂量
1–3 月定期随访：ECG + Holter（每 1–3 月）；评估心律失常控制情况；胺碘酮监测肝功能 / 甲状腺功能；β 阻滞剂监测血糖 / 心动过缓
6 月评估是否可减量 / 停药（见 7.2）；cAVB 评估起搏指征
1 岁全面评估：Holter + 心脏超声；SVT 停药评估（无复发可停）；LQTS 终身 β 阻滞剂；遗传咨询（一级亲属筛查）
长期每年随访 ECG + Holter；LQTS 避免诱因（运动 / 声响）+ 终身用药；cAVB 起搏器随访（电池 / 阈值）；难治性心律失常 → 小儿电生理评估 → 射频消融（年龄 / 体重足够后）

C值班口袋卡

核心八条

  1. 先看稳定性——不稳定（低灌注 / 心衰 / 意识改变）立即电复律，不要先用药
  2. 再看 QRS 宽窄——窄 → 室上性（SVT / AT / 房扑 / JET）；宽 → 一律先按 VT 处理
  3. SVT 三步法——冰水敷面 → 腺苷（大静脉快推 + 冲管）→ 二线药 / 电复律
  4. 三大禁忌——维拉帕米新生儿禁用；WPW+房颤禁腺苷 / 地高辛；LQTS 禁胺碘酮 / 索他洛尔
  5. cAVB 红线 55——室率 <55 立即起搏；55–70 伴低灌注也起搏；必查母亲抗 Ro/La
  6. LQTS 立即用药——QTc>470 即启动普萘洛尔，不等基因结果；TdP 首选镁盐
  7. 良性早搏不用治——单源偶发、无心脏病、无症状 → 安抚 + 随访 Holter
  8. 新生儿不是小成人——传导系统未成熟、旁路 40% 自行消失、维拉帕米禁用、CPR 按 3:1 非 15:2
终极口诀
稳不稳 → 宽窄 → 冰苷电 → 查病因 → 纠诱因 → 记禁忌 → 勤随访。新生儿心律失常，冷静分层，预后大多好。
